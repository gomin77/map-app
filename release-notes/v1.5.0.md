# v1.5.0 출시노트 (versionCode 32)

## 커플 연동 업데이트

- **커플 연동 기능 추가**: 설정에서 초대 코드를 만들어 애인과 연동할 수 있습니다.
- **함께 본 지도**: 연동된 애인과 "함께 본 지도"를 확인할 수 있습니다.
- **선택적 공유**: 내 여행 기록마다 "애인과 공유하기" ON/OFF를 설정할 수 있습니다. 끈 기록은 애인에게 보이지 않습니다.
- **사진·메모·날짜 동기화**: 공유된 기록은 사진, 여행 날짜, 태그, 메모까지 함께 동기화됩니다.
- **지도에 사진 표시**: 함께 본 지도에서도 내 지도와 동일하게 지역에 대표사진이 표시됩니다.
- **대표사진 선택**: 함께 보기 상태에서 내 기록의 ☆/★ 버튼으로 지도 대표사진을 바로 설정할 수 있습니다.

## 개선 및 버그 수정

- 내 지도 / 함께 본 지도 토글 UI 개선
- 커플 연동 시 읽기 전용 보기 안정화
- 초대 코드 복사 시 코드만 복사되도록 개선

## 업데이트 전 확인사항

- 이번 버전부터 커플 데이터 동기화를 위해 Firestore 보안 규칙에 `pairs` 컬렉션 및 `users/{uid}` 파트너 권한 규칙이 필요합니다. (이미 Firebase 콘솔에 반영된 상태)
